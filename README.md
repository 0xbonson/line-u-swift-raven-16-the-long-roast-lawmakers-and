# The Long Roast: Lawmakers and the File They Cannot Convert

```
The same senators drafting criminal penalties for autonomous neural network architectures still print out their emails so an unpaid intern can scan them back in as upside-down JPEGs.
```

### About the Joke
This joke satirizes lawmakers attempting to enact strict criminal penalties on cutting-edge neural architectures while their own offices remain baffled by simple digital document workflows.
